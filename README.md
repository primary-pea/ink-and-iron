# Ink and Iron

Primary Pea, Women in Data Datathon 2026. Live deck: https://primary-pea.github.io/ink-and-iron/ (GitHub Pages from `main`, `/` root).

Source of truth for edits: **this repository, branch `main`.** Edit locally, check in a browser, then push (or open a pull request). The copy under `ramya/deck/` in the team scratchpad repo is the 13 Sep original and is no longer updated.

Preview locally: `python3 -m http.server 8765` in this folder, then open http://localhost:8765/ . The page needs internet for fonts and the GSAP/D3/Lenis libraries; the world map (`assets/world-110m.js`) and the anaemia series (`assets/anaemia_wra_2000_2023.js`) are vendored.

Numbers and figures: scaffold v2.0, data version `afe63e46c26b` (team repo `sarah/scaffold/results/RESULTS.md`). Assets and licences: `assets/MANIFEST.md`, `assets/MANIFEST-fluent.md`; the scaffold figures are in `assets/sarah/`.
